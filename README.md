# Loja do Vino (Umbrel)

Loja comunitária do Umbrel com um atalho para o painel do FlexWatch, que roda no próprio Umbrel (porta 8771).
Não contém código nem dados do FlexWatch: só o ícone e um redirecionamento.

Umbrel → App Store → ⋯ → Lojas da comunidade → cole `https://github.com/TheVino/vino-umbrel-apps`.
